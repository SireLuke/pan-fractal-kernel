# ABOM-V8 occupant continuity templates

These templates implement the documentation contract in PAN-AI-GOV-ADD-001.

- `memory.md` is mandatory for every admitted occupant.
- `soul.md`, `life.md`, and `death.md` are optional.
- Copy the applicable templates into a per-occupant directory; do not edit the shared templates as an occupant's live record.
- Keep the lifecycle registry and authorization records authoritative. These Markdown files are portable records, not permission tokens.
- Separate occupant-local context from shared PAN canon. Memory import never transfers identity, provenance, evidence level, niche eligibility, or permissions.
- Conway's Game of Life in `life.md` and Wa-Tor in `death.md` are optional reference simulations only. Neither simulation models consciousness or determines governance status.

The governing specification is in the PANoRAMic.os repository at `governance/AI_OCCUPANT_GOVERNANCE_ADDENDA.md`. This repository contains templates only; it does not implement automated lifecycle enforcement or simulation engines.
